A modern, responsive, and lightweight personal portfolio web application designed and built from scratch using **HTML5**, **Bootstrap 5**, and custom **JavaScript**. 

This portfolio showcases my academic journey, core technical proficiencies, corporate software development internships, AI/ML certifications, and personal projects.

---

## Highlights & Features

- **Fully Responsive Design**: Mobile-first flexbox layout powered by Bootstrap 5, optimized across desktop, tablet, and mobile viewpoints.
- **Dynamic Rendering Architecture**: Clean separation of concerns with HTML structure (`index.html`), presentation (`styles.css`), and data-driven DOM rendering (`script.js`).
- **Interactive Certificate Lightbox**: Modal-based preview system for reviewing professional certificates, credentials, and internship documentation.
- **Serverless Contact Pipeline**: Integrated directly with **Formspree** for instantaneous, backend-less contact form submissions sent straight to inbox.
- **Fluid UI Animations**: Subtle CSS3 `@keyframes` floating header effects, card elevations, and hover transitions.
